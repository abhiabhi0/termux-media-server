TERMUX MEDIA SERVER - QUICK COMMANDS
=====================================

This is a plain-text reference. View it in Termux with:
  cat ~/notes/QUICK_COMMANDS.txt
Or edit/view it with:
  nano ~/notes/QUICK_COMMANDS.txt


1. START / RECOVER SERVICES
---------------------------

Start SSH, native or legacy Jellyfin (if configured), and File Browser (if configured):
  bash ~/bin/start-media.sh

This is normally handled automatically when a Termux shell opens. For startup after Android reboot, install and open the Termux:Boot Android app once; see the README. Also set Termux and Termux:Boot battery usage to Unrestricted where available.

Check all service processes and local web endpoints in one command:
  media-status

Set your Termux SSH login password (only if you have not already set one):
  passwd

Check Termux username:
  whoami

SSH normally listens on port 8022. Keep File Browser authentication enabled and use Tailscale for remote access rather than exposing File Browser directly to the public internet.


2. INDIVIDUAL CHECKS
--------------------

  pgrep -af sshd
  pgrep -af jellyfin
  pgrep -af filebrowser
  pgrep -af aria2c

If a command prints a matching process line, the process is running. aria2 normally runs only during downloads.

Check local web endpoints:
  curl -I http://127.0.0.1:8096
  curl -I http://127.0.0.1:8080

Jellyfin may return "302 Found" and redirect to /web/; that is normal. On 32-bit ARM Termux, use the optional legacy Jellyfin 10.10.7 setup documented in README.md. It runs inside Debian/PRoot and uses Termux FFmpeg.


3. SIMPLE DOWNLOADS
-------------------

Use the simple "dl" helper. Run:

  dl

Then paste a URL, magnet link, local .torrent path, or remote .torrent URL when prompted.

Examples if you want to provide the link on the command line:

  dl "https://example.com/file.zip"
  dl "magnet:?xt=urn:btih:..."
  dl "https://example.com/file.torrent"
  dl "~/storage/shared/Download/file.torrent"

IMPORTANT:
- Downloads are saved in ~/storage/shared/Download.
- A remote .torrent URL is processed as a torrent by aria2 when its URL ends in .torrent or the server returns the BitTorrent content type. It starts downloading the torrent contents, rather than saving only the .torrent file.
- When passing a magnet link as an argument, wrap it in quotes because it can contain '&'. Running "dl" without arguments and pasting at the prompt avoids shell quoting issues.
- aria2 shows progress in the terminal. Ctrl+C interrupts the foreground process; rerun the same link to resume where supported.
- Seeding stops after completion.
- Only download content you have permission to access.

Check active downloads:
  pgrep -af aria2c

List downloaded files:
  ls -lh ~/storage/shared/Download


3A. LEGACY JELLYFIN ON 32-BIT ARM
--------------------------------

Run the installer on a 32-bit ARM Termux phone:
  curl -fsSL https://raw.githubusercontent.com/abhiabhi0/termux-media-server/main/setup-legacy-jellyfin.sh -o "$HOME/setup-legacy-jellyfin.sh" && bash "$HOME/setup-legacy-jellyfin.sh"

Manually start the legacy server:
  bash ~/bin/start-legacy-jellyfin.sh

Check service health:
  media-status

Legacy Jellyfin logs:
  tail -f ~/.local/share/media-server-logs/jellyfin-legacy.log
  tail -f ~/.local/share/media-server-logs/jellyfin-launcher.log

Legacy server URL on your private Tailscale network:
  http://PHONE_TAILSCALE_IP_OR_NAME:8096

First-time login:
- The first-run wizard lets you create a Jellyfin username and password; there is no universal default login.
- These credentials are separate from Termux SSH and File Browser credentials.
- If server discovery finds nothing, choose Add Server and enter the base URL above.

Add the phone's internal shared storage as a library folder:
  /storage/emulated/0

This is shared internal storage, including Download, Movies, DCIM and Pictures; it does not include private app data or Android system partitions.
If the Jellyfin folder picker cannot browse /storage/emulated/0 in this PRoot setup, /sdcard is a compatibility alias to the same internal shared storage, not an external SD card. Confirm access with:
  termux-setup-storage
  ls -la ~/storage/shared
  proot-distro login debian -- ls -la /sdcard

Check the server's setup wizard state:
  curl -sS http://127.0.0.1:8096/System/Info/Public

If it says StartupWizardCompleted=false but Jellyfin still displays a sign-in page, do not guess a password or delete the database. See docs/legacy-jellyfin-arm32.md for read-only diagnostics.

The script installs Jellyfin 10.10.7 server and web packages in Debian Bookworm armhf. It uses Termux FFmpeg bound into PRoot because the Debian Jellyfin FFmpeg binary may not run on Android/PRoot. This is an old release; do not expose it to the public internet.

4. ACCESS SERVICES OVER TAILSCALE
----------------------------------

Replace PHONE_TAILSCALE_IP_OR_NAME with this phone's current Tailscale IP or MagicDNS name.

Jellyfin:
  http://PHONE_TAILSCALE_IP_OR_NAME:8096

File Browser:
  http://PHONE_TAILSCALE_IP_OR_NAME:8080

SSH from Windows PowerShell:
  ssh -p 8022 YOUR_TERMUX_USERNAME@PHONE_TAILSCALE_IP_OR_NAME

Find the Termux username:
  whoami


5. LOGS AND STORAGE
-------------------

Jellyfin log (if installed):
  tail -f ~/.local/share/media-server-logs/jellyfin.log

File Browser log:
  tail -f ~/.local/share/media-server-logs/filebrowser.log

SSH startup errors:
  tail -f ~/.local/share/media-server-logs/sshd.log

Termux:Boot startup log:
  tail -f ~/.local/share/media-server-logs/boot.log

aria2 process:
  pgrep -af aria2c

Check available storage:
  df -h


NOTES
-----

- Android may stop background services/downloads to save battery. Set Termux and Termux:Boot battery usage to Unrestricted where available.
- The startup script and boot hook use termux-wake-lock if available, but Android can still terminate processes.
- For startup after reboot, install and open the Termux:Boot app once from the same source as Termux.
- Preferred service startup command: bash ~/bin/start-media.sh
- On legacy ARM32 devices, start-media.sh launches legacy Jellyfin in the background after its installer has been completed.
- Run media-status to check services without memorizing separate commands.
- Use "dl" for downloads instead of memorizing aria2c options.
- Only download or share content you have permission to access.
